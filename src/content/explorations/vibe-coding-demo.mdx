## 前期快速对齐方向

借助 AI Studio，将初步的 Figma 静态设计稿快速转化为可交互 Demo，并通过多轮对话探索不同的设计方案，辅助团队在设计早期验证思路、对齐方向。

**实践过程：** 基于一版初步的 Figma 静态设计稿，经过约 7–8 轮对话迭代，完成从静态界面到可交互 Demo 的快速构建。

## 借助 Figma Agent，快速发散 UI 设计方案

借助 Figma Agent，基于现有的 B 端「权益与用量」页面，围绕信息架构、视觉层级和数据表达方式快速探索多种设计方向，辅助设计前期的方案比较与方向判断。

**实践过程：** 以原始 Figma 设计稿为基础，明确保留现有业务信息、数据和功能，通过 Prompt 限定不同的设计策略，让 Agent 一次性产出 4 套方案，并从信息查找效率、视觉重点及信息组织方式等维度进行对比评估。
